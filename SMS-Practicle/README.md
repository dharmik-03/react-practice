## ✨ Features

- **Student Management:** Organize and manage student records.
- **Add Students:** Add new student information.
- **Edit Students:** Update existing student details.
- **Delete Students:** Remove student records when no longer needed.
- **Responsive UI:** Designed for a clean experience across different screen sizes.
- **Modern Frontend:** Built with React and Vite for a fast development experience.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Styling:** CSS, Bootstrap
- **Code Quality:** ESLint
- **Deployment:** Vercel
